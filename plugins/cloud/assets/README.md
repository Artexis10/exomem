# Cloud plugin icons

These assets use the approved Dot E brand kit from 13 October 2026.
The mark uses warm black, phosphor amber and off-white on a dark tile.

- `icon.svg` contains the approved full mark only. Claude's plugin validator rejects an SVG icon with a `style` element, so the SVG has no size-dependent compact variant.
- `icon.png` is the approved 512-pixel directory icon: a 5 × 7 grid with four amber dots in the middle arm.
- `icon-small.png` is the approved 48-pixel compact asset for the OpenAI composer. It uses the 3 × 5 mark.

The PNG files preserve the approved kit bytes.
Provider rasterisation can change how the SVG renders at small sizes; inspect the actual dashboard preview before submission.
