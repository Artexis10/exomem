# Exomem Cloud

Exomem Cloud gives assistants governed long-term memory across conversations. It keeps original sources and evidence separate from compiled conclusions, and connects related knowledge without treating a summary as its source. The bundled skills explain recall, continuity, capture and review. Connect the remote MCP server through your provider's authorization flow.
