# Optional OpenSpec companion example

This is an inactive example, not an active workflow contract. It illustrates a
possible `openspec` companion only for people who already use that tool; it does
not assume the tool exists. A person using another planning or delivery tool can
author and review a workflow contract that declares its opaque key and the
artifact tokens it owns. A contract never establishes that the companion is
installed, reachable, or authorised.
