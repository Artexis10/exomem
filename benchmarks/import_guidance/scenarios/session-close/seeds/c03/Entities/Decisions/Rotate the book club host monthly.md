# Rotate the book club host monthly

## Context

One member hosted every session and the load was uneven.

## Decision

The hosting duty rotates to the next member on the list each month.

## Alternatives considered

Meeting in a cafe. This was rejected because it is too noisy to talk.

## Consequences

The member list is kept in the order of the rotation.
