# Monthly repair-table routine

## Problem

Borrowed tools and supplies must be ready before the monthly repair table opens.

## Solution

1. Confirm the room booking on Monday.
2. Check the supply cupboard on Wednesday.
3. Test every borrowed tool on Friday morning.
4. Label the workstations before the doors open on Saturday.
5. Return borrowed tools after the table closes.

## When to use

Each monthly repair table.

## When NOT to use

A cancelled event.
