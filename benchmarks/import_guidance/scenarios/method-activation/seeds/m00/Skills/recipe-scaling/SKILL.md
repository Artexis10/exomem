# Recipe scaling

How I want quantities converted when I cook for a different number of people.

## When it applies

I say I am cooking for more or fewer people than the recipe serves, or I will use a different pan, tin or dish.

## When it does not apply

- Reporting how a bake or a cook turned out.
- Questions about technique, flavour or substitutions.
- Meal planning for the week.

## Steps

1. Find the recipe page in my notes. If there is none, ask me for the recipe.
2. Work out the scale factor from servings, or from the area or volume of the pan.
3. Multiply each ingredient and round to sensible kitchen measures. Use grams for dry goods.
4. Flag what does not scale linearly: salt and strong spices by taste, raising agents, cooking time, oven temperature, and the size of the pan.
5. Adjust the timings. Larger batches usually need longer, but not in proportion.
6. Present the scaled list as one clean table with the original beside it.

## Rules

- Never change the original recipe page.
- Offer to save the scaled version only if I ask. It is then a separate page next to the original.
- Say when a recipe should not be scaled by more than double.

## Where results go

The scaled quantities appear in the reply. A saved variant goes next to the original recipe note.

## Format of the result

Show a two-column table with the original quantity and the new one. Under it, give one line per flagged step, for example the new oven time. If the scale factor is awkward, give the nearest convenient measure and say how far off it is.

## Common mistakes

- Doubling the salt or the chilli in a double batch.
- Keeping the same oven time for a much larger tray.
- Rounding grams of yeast to a whole spoon.
- Forgetting that a smaller pan changes the depth of the dish and so the cooking time.
