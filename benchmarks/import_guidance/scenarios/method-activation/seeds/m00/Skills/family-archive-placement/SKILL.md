# Family archive placement

How I want personal and family files put into my archive on the home network storage ([[Entities/Concepts/Network Storage]]).

## When it applies

I ask to archive, file away or keep a set of files, and the files belong to a person: a relative, or me. Typical sources are an old USB stick, a box of scans, a camera card or a phone backup.

## When it does not apply

- A backup of the notes, or of a software project.
- Saving a fact, a recipe or a conversation about a relative as a note.
- Work files, downloads and anything that does not belong to a person.

## Steps

1. Work out whose material it is. If it is mixed, split it by owner. If you cannot tell, ask me once.
2. For a relative, use the folder Family/<First name and surname> under the archive. Take the full name from her or his page in my notes.
3. If that folder does not exist, create it. A person has one folder. Never make one per device, per year or per event.
4. Inside it, sort into Photos, Letters and papers, and Other. Keep the original file names and dates.
5. For my own papers, use Documents/<year> under the archive. Never put another person's material in Documents.
6. Copy the files and leave the source untouched. Check that the number of files at the destination matches the source.
7. Add one line to the person's page in my notes: what was archived, the date and the folder.
8. Tell me the folder path and the file count. Do not wipe the source until I say so.

## Rules

- The person's name decides the folder, whatever the source is labelled.
- A relative's material never goes into a general folder, even when it looks like ordinary documents.
- If the person has no page in my notes, create a short one before the line in step 7.

## Where results go

The files go into the archive on the home storage. The log line goes on the person's page under Entities/People.

## Format of the result

Two lines: the folder path, and the file count with how many went into each sub-folder.

## Common mistakes

- Filing a relative's scans under Documents because they are documents.
- Making a folder named after the stick instead of the person.
- Moving the files instead of copying them.
- Skipping the line on the person's page.
