# Reading notes

How I want what I read turned into something I can find later.

## When it applies

I say I have finished, or am partway through, a book, an article, a paper or a long video, and I want to hold on to the substance or talk it over.

## When it does not apply

- A request to verify a claim with primary sources. That is research.
- A decision about trying a tool in one of my projects.
- Casual mention of something I read with no wish to keep it.

## Steps

1. Ask for the title and author or site if I did not give them.
2. Look in my notes under Notes/Research/reading for a note on the same work. Extend it if it exists.
3. Write three to six main points in my words, not a summary of the whole piece.
4. Add at most three short quotes, each with its page or time.
5. Add one line that says what I want to do with it, or that nothing follows.
6. Link the author or the topic if a page exists.
7. Capture the original as a Source when it is an article, paper or web page.

## Rules

- Keep my opinion apart from the author's claims.
- Do not fetch or paraphrase text I did not mention.
- A note is short. If it grows past a page, split it.

## Where results go

One research note per work under Notes/Research/reading, such as [[Notes/Research/reading/the-quiet-orchard]].

## Format of the note

Use these headings: Question, Findings, Quotes, What I will do with it. Keep the findings as a short list of full sentences. Put the title and author on the first line so the note can be found by either. Date the note with the day I finished reading.

## Common mistakes

- Writing a book report instead of notes.
- Copying long passages that I could look up again.
- Mixing the author's argument with my reaction to it.
- Creating a second note for a book I already have a note on.
