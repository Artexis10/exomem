# Book the return ferry first

## Claim

On a trip with a single return crossing, book the return ticket before anything else, because it is the booking with the least slack.

## Why it holds

Rooms and meals can usually be changed or replaced. A sold-out last sailing strands the whole group for another day.

## Where it applies

Any trip with a ferry, a rural train or a single flight home.

## Counter-considerations

Booking early locks the dates, so check the forecast and everyone's calendar first.
