# Home NAS build

## Question

Which parts make a quiet, low-power network storage box for photos, backups and the occasional database copy?

## Findings

- A small low-power processor and 16 GB of memory are plenty for file serving.
- Two mirrored drives suit the capacity needed and keep the build quiet.
- A case with a large slow fan keeps the box inaudible in the hallway cupboard.
- Weekly snapshots and an offsite copy matter more than the drive model.
