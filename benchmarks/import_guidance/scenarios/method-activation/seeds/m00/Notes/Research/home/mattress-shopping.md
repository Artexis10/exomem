# Mattress shopping

## Question

Which mattress type suits a side sleeper with occasional lower-back pain?

## Findings

- Memory foam contours to the shoulders and hips, which relieves pressure, but many models sleep warm.
- Pocket-sprung mattresses sleep cooler and bounce more.
- Hybrids combine a spring base with a foam top and cost the most.
- A 100-night home trial matters more than the spec sheet.

## Open threads

- Visit two shops and lie on each for ten minutes instead of two.
- Check whether the trial period allows returning a mattress that has been slept on.
