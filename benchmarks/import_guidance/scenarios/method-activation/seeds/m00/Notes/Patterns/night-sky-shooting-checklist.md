# Night sky shooting checklist

## Problem

Dark-sky trips are rare, and a missed setting wastes the clear night.

## Solution

1. Check the moon phase and cloud forecast two days ahead.
2. Arrive before dusk and scout the foreground in daylight.
3. Focus on a bright star using live view at maximum zoom, then tape the ring.
4. Start at 15 seconds, wide open aperture and a high ISO, and adjust from the first frame.
5. Keep warm; shoot a spare set of frames for stacking.

## When to use

Any clear night away from town lights.

## When NOT to use

Nights with a bright moon above half full.
