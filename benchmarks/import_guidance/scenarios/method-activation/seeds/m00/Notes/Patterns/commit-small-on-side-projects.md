# Commit small on side projects

## Problem

Evenings are short and interrupted. A half-finished change left uncommitted is hard to pick up a week later.

## Solution

1. End each session with a commit, even a rough one, and a one-line note of the next step.
2. Keep each commit to one idea so it can be reverted alone.
3. Rewrite the history only before sharing a branch.

## When to use

Any personal project worked on in short sessions.

## When NOT to use

Shared branches where others depend on a clean history.
