# Import guidance probe

This probe proves that a real headless agent follows the Cloud import tool text when a scripted server shows it the states that text describes. Scenario files in `scenarios/` script the replies of the four Cloud import tools, served with the shipped descriptions and schemas, and the agent gets the shipped skill text. Deterministic checks read the server's call log; a second `claude -p` judges the agent's words against each criterion, and a run error or an unreadable judge answer is `unknown`. Run it from the repository root with `PYTHONPATH=benchmarks python -m import_guidance run --model <m> --repeats N --scenario <id|all> --out <dir outside every repository>`, or add `--dry-run` to start no model. To add a case, copy a scenario file, script its replies, list its `checks` and `criteria` (each with the value it expects), and run `--dry-run`. Each failure found later becomes a permanent scenario here.
