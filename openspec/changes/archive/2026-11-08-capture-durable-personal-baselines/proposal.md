Retirement scope (2026-10-11): Retirement supersedes Hosted v5 packaging and historical-profile gates. Shared baseline doctrine and client acceptance remain in scope. Pending client traces and closure still require surviving implementation and merge evidence.

## Why

The active capture predicate names conclusions, recurring entities, executed methods, intent, and outcomes, but omits stable preferences, recurring habits, historical baselines, and durable memberships expressed in casual prose. Agents therefore stay quiet on reusable longitudinal context merely because it arrived conversationally, forcing the user to ask whether Exomem should have remembered it.

## What Changes

- Add `durable personal baseline` as an explicit stepping-stone capture class across every active agent contract carrier.
- Cover stable preferences, recurring habits/routines, historical quantitative or contextual baselines useful for later comparison, and durable affiliations or memberships.
- Preserve the existing precision bar: fleeting preferences, one-off activities, incidental subscriptions/associations, mundane trivia, and unresolved claims remain unwritten.
- Route a baseline according to meaning: update a uniquely resolved Entity for a stable facet or affiliation; otherwise write one concise compiled observation; use Records only for a compatible observed event or measurement.
- Keep the already-shipped executed-method predicate separate and regression-pinned rather than broadening it into a catch-all.
- Add synthetic positive/negative agent-behaviour fixtures, carrier-parity tests, and mutants that remove the durability or reusable-comparison discriminator.
- Deliver pending baseline, generated-artifact adoption, recurring-entity lifecycle, and governed-curation doctrine through the retained Cloud packages after their shared fixtures are integrated.
- Preserve immutable historical Hosted packages and their original promotion evidence.

## Capabilities

### New Capabilities

- `durable-personal-baseline-capture`: The domain-neutral eligibility, routing, precision, and falsification contract for stable personal and longitudinal context stated in ordinary conversation.

### Modified Capabilities

- `agent-bootstrap-contract`: Bootstrap and prominence payloads explicitly carry the baseline class and its positive/negative boundary.
- `portable-agent-contract`: Installed scaffold, workflow skill, hooks, copyable custom instructions, and retained Cloud packages carry one coherent capture predicate after shared fixture integration.
- `delegation-envelope`: Baseline capture, additive Entity facets, affiliation links, and structural Entity changes map explicitly to the existing authority classes.

## Impact

Affected areas include the generic scaffold, capture workflow skill, bootstrap/prominence payloads, local hooks, assistant documentation, custom-instruction blocks, delegation teaching, shared behavior fixtures, and retained Cloud packages.
Leak guards and no-nudge benchmark fixtures remain in scope.
The change adds no server-side semantic decider and no background processing.
