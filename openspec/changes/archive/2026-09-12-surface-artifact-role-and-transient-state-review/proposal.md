## Why

A page can accumulate a reusable method or a research synthesis while staying on one topic, so topic-divergence checks miss the need for a separate home. Earlier wording such as “no result yet” can also remain presented as current after the same experiment records an outcome, leaving the user to notice both problems.

## What Changes

- Add deterministic `artifact_role_promotion` and `transient_state_review` signals over authored semantic units. Each points to bounded supporting units; the active agent decides what to extract or correct through existing governed writers.
- Recognize an explicitly reusable, reported-success method and attributed multi-source synthesis inside an experiment without requiring unrelated topic vocabulary. Resolve promotion when a readable role-appropriate destination represents the identified material, including splits that retain the original history.
- Flag a narrowly evidenced pending-to-result transition for the same experiment episode. Historical statements, quoted material, unrelated trials and ambiguous ordering remain quiet; the signal never declares a general semantic contradiction.
- Maintain the signals through page write deltas and audit reconciliation, then use existing attention and due-state carriers. Respect audience visibility, freshness, item decisions, family dispositions and connector response budgets.
- Extend agent guidance and generic replay acceptance to teach role-first destination choice and current-state hygiene. Records claims routing remains the destination mechanism for observed state; this change adds no collection writer or new page taxonomy.

## Capabilities

### New Capabilities

- `artifact-role-review`: Role-transition detection, narrow transient-state checks, evidence identity, destination resolution and bounded projection maintenance.

### Modified Capabilities

- `attention-queue`: Register both review families with shared visibility, disposition and due-state behavior.
- `agent-bootstrap-contract`: Teach how the active agent handles role and state signals under existing mutation authority.
- `epistemic-state-bench`: Add immutable same-topic promotion and transient-state replay families with negative controls and state-based settlement assertions.

## Impact

Depends on the merged collection-claims change in #1212 and the existing connector request budget. Likely code seams are a new pure detector module, `audit.py`, `due_state.py`, review-family registration and the bootstrap/scaffold carriers. Existing semantic parsing, relation resolution, post-commit delta handling and mutation tools remain the substrate.

No new tool, input schema, mandatory model, background conversation observer or automatic mutation is introduced. Detection is deterministic and enabled with ordinary review measurement; failures soften to unknown or omitted advice and never change a committed write. Existing audit/reconcile operations own corpus work; synchronous writes add no corpus scan, embedding call or destination-file read. This proposal defines the next implementation, not a claim that it is deployed.
