## Why

The no-nudge core is two slices in and one short. `close-write-warning-suppression` gave write-path advisories dismissal memory, and `add-due-state-consumers-and-carriers` now carries a due-state block to every client on writes, recall, and bootstrap. What neither slice gives the user is a way to say "stop suggesting this *kind* of thing": triage state is per item, so a family the user has decided is noise for their corpus comes back with every new page that trips it, and the only escape is prominence `off`, which silences everything. The habituation risk the architecture report ranks as the top product risk is therefore still open at the family level.

The same report made "more automatic" a measured claim, and the measurement has no inputs. Nag rate, recovery fraction, and manual-maintenance counts are computable only from state the runtime does not keep: when a signal was first surfaced, why a dismissal was made, and whether a state change was a person's decision or the runtime's own transition. The bench's f23 family asserts counter-emission governance under bulk writes, but the emission governor is in-process state that no projector can read, so the bench still declares the counters block unavailable. And the store all of this would live in — `.review-state.json` — is a whole-file JSON rewrite per decision behind a fixed 4 MiB read limit, with no retention, no compaction, and no migration path; "grows with decisions" is not a scaling answer once first-surfaced records and dispositions join it.

## What Changes

- **Per-family dispositions.** A user or agent can set a registered signal family to `normal`, `quiet`, or `off` through the existing triage surface using a family review reference; the decision is recorded with the same auditability as an item decision (reason, why, timestamp, origin) and persists across restarts and prominence changes until reset. `quiet` removes the family from the default attention union, from every due-state carrier, and from write-path advisory emission, while leaving it reachable on explicit category review; `off` additionally removes it from explicit category review except the all-states view. Audit measurement is unaffected: sensors measure regardless of disposition.
- **Closed triage-reason vocabulary.** Dismissals and family dispositions record a reason code from a closed vocabulary. The code rides the existing `why` field as a leading token so no tool input schema changes for it; the CLI gains a flag that composes it. An absent or unrecognised token records `unspecified` and never rejects the decision.
- **First-surfaced ledger.** The review state records, per `(review identity, fingerprint)`, when a signal was first composed onto a served surface and which surface that was. It starts empty, populates on first surfacing, is never backfilled, never records anything withheld by egress or by disposition, and is failure-isolated from the read that populates it.
- **Origin tags.** Every review-state record carries `origin: manual|automatic` — manual when recorded through the explicit triage surface, automatic when the runtime wrote it itself — so the manual-maintenance metric is computable from the store.
- **Emission capture and batch-once emission.** The due-state projection persists an emission ledger (emission count and write count) that a projector can read, and a single product command that commits more than one governed write emits its due-state block at most once, at the end of the batch. The bench's f23 family runs against the real runtime through a journey driver, and the projector flips `due_state_counters` from unavailable to available.
- **Store scaling.** The review-state store moves to a sectioned schema (records, dispositions, surfaced ledger, stats) with forward migration from the current schema, retention rules, compaction on write past declared thresholds, a raised hard read limit, and a stress gate at multi-year cardinality whose failure is the declared trigger for the append-plus-compaction or SQLite migration the roadmap keeps in reserve.

## Capabilities

### Modified Capabilities

- `attention-queue`: family dispositions and their effect on the default union, explicit category review, carriers, and write advisories; the closed reason vocabulary; the first-surfaced ledger; origin tags; the sectioned review-state schema with migration, retention, compaction, and the stress gate.
- `command-surface`: family review references and the three disposition actions on the triage surface; a dispositions view on the review surface; batch-once due-state emission on multi-write commands; the persisted emission ledger; the tool descriptions regenerated through the documented two-phase tool-surface rollout.
- `agent-bootstrap-contract`: the engagement guidance teaches reason codes on dismiss, family dispositions as the answer to "stop suggesting this kind of thing", and that a quiet family is silent rather than absent.

## Impact

`review_state` (schema v2, dispositions, ledger, origin, compaction, stress gate), `attention` (disposition filtering and annotation, ledger population), `corpus_aware` (disposition-aware advisory emission), `due_state` (disposition-aware counting, persisted emission ledger, batch scope), `commands` (family refs and actions on `triage_memory`, `review_memory(mode="dispositions")`, batch scope on multi-write leaves), the CLI `review` subcommands, bootstrap guidance and scaffold regeneration, the bench projector and a new f23 journey driver, and focused tests. The tool-surface fingerprint moves because the `triage_memory` and `review_memory` descriptions now describe the family actions and the dispositions view; the move is budgeted through `scripts/dump-tool-schemas.py` and recorded as a pending digest per the documented rollout. No new front-door tool, no new tool input parameter. Write-latency gates hold: disposition lookups are one store read already on the path, and the ledger write is best-effort behind the same lock. S7's delegation envelope (ceilings, prominence-derived defaults, the three-declines offer) is explicitly out of scope; this change supplies the state S7 reads.
