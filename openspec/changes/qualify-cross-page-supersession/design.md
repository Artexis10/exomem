## Context

Current-context projections admit unit text before applying currency. The same-page rule has both ends in memory. A cross-page replacement can come from an inspection that provides no stance or profile lines.

## Decisions

Reuse the graph's typed unit relations and the correction reader's snapshot checks. In personal recall with unrestricted source access, stance, domain profiles and recorded positions check the admitted candidates before selecting the lines that fit. A single successor can retire several predecessors. Resolve both ends for authored and stored relations with their exact unit identities. Use the source page's relation registry. Apply the result before the current lines enter the cache. Keep source identities and relation data internal.

Batch lookups on the graph's existing destination-page index. The selected parser lands each fragment on an exact occurrence, including units with vault-defined headings. Check the source unit's validity before applying its replacement. Share one lookup across all selected domain profiles. Limit a lookup to 64 candidate edges and 32 distinct source pages under the caller's deadline and a 100 ms allowance. A store snapshot with pending derivation or a lookup with incomplete coverage reports unavailable.

Shared recall requires a separate qualification step before it can use cross-page edges for currency. A readable source page can hold a unit whose own text is withheld. The page admission cache cannot prove which exact units count for a shared reader.

The vault load target is 20,000 pages, about 100,000 units and 120,000 edges. Check a 10,000-link hub and that a shared caller's packet stays independent of withheld successors. Compare with the existing activation p95 allowance of 10%.

Use the contradiction queue on disposable data for candidate pairs and the supersession audit for declared page pointer defects. Treat proximity as a shortlist. A reviewer compares the entity, facet, dated evidence and incompatible claims before flagging a conflict or authoring a replacement through the existing write path. In a bounded audit, record the input scope, evidence window, pairs inspected and any uninspected remainder. Count linked replacements, evidence-backed unlinked conflicts, ambiguous claims and declared defects separately. Report store-wide coverage as unknown without a verified census. Keep these comparisons off recall.

The predecessor stays readable with its original source. A newer date, a similar phrase or a contradiction alone leaves its currency unchanged. Existing page and same-page behaviour still applies.

This follows the bounded retrieval approach in [Effective context engineering for AI agents](https://www.anthropic.com/research/effective-context-engineering-for-ai-agents). The project uses a typed relation as its authority for currency.

## Verification and release

Use the same disposable fixture before and after. It gives a visible replacement outside the initial current-context set and an unrelated sibling. Include path-backed endpoints. Confirm that personal recall drops the linked predecessor and that an explicit read still returns its text. Reuse a continuation after a replacement changes to check that the old generation does not stay current. Compare shared readers' output with withheld successors present and absent.

Run the regression, existing currency and egress checks and a bounded load check before delivery. The ordinary release needs no migration. Revert the code to restore the prior projection if acceptance fails. Verify the release on disposable data.
