An unreadable media ledger leaves a missing original's record in place, and a hard link or a symlink is judged as it is without a media store. `test_a_new_original_that_a_store_mode_vault_offloads_can_then_be_evicted_and_restored` offloads a new original in a store-mode vault (`media_store._publish_reference` reads the stored page back there, not the Markdown file), then evicts and restores it with the same unchanged rows and no held item.
