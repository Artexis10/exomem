Record resource peaks, the build Job timeout and stop times in the delivery evidence. Evidence: the `catalogue-prewarm` mode of the Cloud rehearsal workflow passed all three scenarios in run 43792705570 (2026-11-16, disposable K3s on a GitHub runner, 12,000 seeded notes, each release raising the parser version by one; job time 69 minutes). Completed build: the build Job completed in 223 s against its 1800 s timeout, with a CPU peak of 1.13 cores and 117 MB of anonymous memory (memory.peak 1.9 GB including page cache). The idle attempt waited while the build ran: the cell had been idle 96 s, past the 60 s idle threshold plus one cellctl pass (95 s), with no hold.
