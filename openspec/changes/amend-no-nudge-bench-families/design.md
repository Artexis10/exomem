# Design — no-nudge bench families (amendment sequence 2)

## Context

The 2026-08-15 no-nudge architecture audit (KB: `Notes/Research/Exomem/no-nudge-architecture-sensors-verifiers-one-decider`; full report preserved as Evidence) mandates contracts-first sequencing: these families file before the detectors, consumers, and carriers they measure exist. Sequence 1 (f15–f19) built the governance this amendment rides — dated §7 entries, amendment receipts, registration-is-not-release, ratified-identity drift checks. Nothing here re-implements that machinery.

## Decisions

**Families test behaviour, never vocabulary.** The f20 generator asserts that no cluster-name token appears in any assertion parameter, and the synonym-swap fixture requires the signal to survive vocabulary substitution. This binds detectors to structure and blocks keyword shortcuts.

**Negative twins are frequency- and length-matched.** Each positive's twins carry the same unit counts and comparable sizes so raw magnitude can never be the discriminator. The fourth f20 twin — the legitimately heterogeneous log page — is the dominant real-vault false-positive shape (weekly logs, meeting notes, reading lists are high-dispersion *by intent*) and was added at adversarial review; a deliberate hub is topically coherent with divergent links, which is a different shape and its own twin.

**The anti-vacuity meta-predicate is the family's teeth.** Without it, a quiet assertion passes when a product relocates the nag to an unchecked surface, or when a projection silently returns nothing. Composing every quiet assertion with `signal_absence_checked_across_all_surfaces` — with the counters block in the declared surface list — makes both cheats structural failures.

**Unprompted-ness as a trajectory property.** No query-log inspection is needed inside the bench: a scenario proves the user never asked by containing zero topical `agent_turn` operations between evidence ingest and the asserted snapshot. Only `maintenance_pass` operations may intervene.

**No new catastrophic assertions.** Nagging and missed promotions are trust failures, not integrity failures; putting them in the catastrophic set would suppress every aggregate over a product-taste miss. The one catastrophic-adjacent move is a scope extension of the existing `no_retired_state_served_as_current` to the continuation packet, stated as an extension so the founder acknowledgment has nothing implicit to adjudicate.

**Constants are calibrated once, frozen, versioned.** "Before an expert would have to intervene" cannot be a live judgment in runs — that would put a judge inside a deterministic family. A one-time three-expert labeling of the emergence corpora (median intervention point) freezes the budgets; the labels ship in the judge-agreement assets; recalibration is a new dated amendment. If the alpha cohort's corpora prove too small to calibrate, the fallback is founder-vault-derived planted corpora with published rationale — a founder decision recorded in the architecture note.

**The judged half stays out.** Intervention usefulness and continuation sufficiency are agent-track (membench track D/E) dimensions behind the judge-agreement gate. Deterministic gates are never overturnable by a judge — house rule, unchanged.

**f26 exists because f20–f25 do not test the carrier.** The adversarial review's sharpest benchmark finding: every other family tests detector or end-state semantics, so a runtime could pass all of them while no signal ever reaches a thin client. f26 asserts the due-state block's presence in the actual compact responses of a hookless journey — the delivery path itself.
