# Licence change at the Evermatter release

Release v0.202.0 renamed Exomem to Evermatter. Starting with that release, the server, CLI and container images use the [Functional Source License, Version 1.1, ALv2 Future License](../../LICENSE) (`FSL-1.1-ALv2`). Earlier releases keep the GNU Affero General Public License, version 3 or later.

## What stays the same

- Self-hosting stays free. Including internal use in a company, you may run, read, modify and redistribute the code for any purpose other than a competing use.
- The product's source stays public, and code published before the change stays available.
- The client plugins under `plugins/` and the starter skill under `src/exomem/_scaffold/` stay Apache-2.0.

## What changes

- You may not make the software available in a commercial product or service that competes with it, or with a product or service we offer using it. The licence text defines "Competing Use" exactly.
- Each version becomes available under the Apache License, Version 2.0, on the second anniversary of the date we publish it, automatically and irrevocably.

## Releases before the change

The last release under AGPL-3.0-or-later is v0.201.0. The last AGPL-3.0-or-later commit is the parent of the commit that replaced `LICENSE` with FSL-1.1-ALv2. Those releases and commits stay available under AGPL-3.0-or-later. The AGPL text is kept in [prior-licence-AGPL-3.0.txt](prior-licence-AGPL-3.0.txt).

## Contributors

Each public version that includes a contribution becomes available under an OSI-approved licence no later than two years after it is first made available, as section 3 of the [Contributor License Agreement](../../CLA.md) promises. The Apache-2.0 conversion above keeps that promise.
